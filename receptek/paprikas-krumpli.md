# 🥔 Paprikás krumpli

**Kategória:** Főétel
**Elkészítési idő:** ~50 perc
**Adag:** 4 fő *(5 főre érdemes 1,2 kg krumplival és 60 dkg kolbásszal számolni)*
**Fehérje:** kolbász

## Gyerekek
- 🔴 Legnagyobb gyerek — nem eszi
- 🟢 Középső gyerek — eszik
- 🔴 Legkisebb gyerek — nem eszi

---

## Hozzávalók

| Összetevő | Mennyiség | Megjegyzés |
|-----------|-----------|------------|
| Krumpli | 1 kg | kockázva |
| Kolbász | 50 dkg | fele kisütve, fele nyersen karikázva kerül bele |
| Sertészsír | sütéshez | |
| Vöröshagyma | 3 fej | aprítva |
| Fokhagyma | pár cikk | aprítva |
| Paprika | 1 nagyobb db | aprítva |
| Paradicsom | 1 nagyobb db | |
| Fűszerpaprika | 1 ek | |
| Babérlevél | 1-2 db | |
| Só, bors | ízlés szerint | |
| Petrezselyemzöld | néhány szál | a végén |
| Víz | igény szerint | majdnem ellepje a krumplit |

---

## Elkészítés

1. A kolbász **felét** zsírban kisütjük, majd kiszedjük és félretesszük. *(Ez lesz a sült kolbász, ami a végén kerül vissza.)*
2. Ugyanabban a zsírban az aprított hagymát megpároljuk.
3. Hozzáadjuk az aprított paprikát és paradicsomot, puhára pároljuk.
4. Hozzáadjuk a fokhagymát, majd 1 evőkanál fűszerpaprikát — elkeverjük.
5. Belerakjuk a kockázott krumplit, sózzuk, borsozzuk, babérlevelet teszünk bele.
6. Felöntjük vízzel, hogy majdnem ellepje.
7. Főzzük, amíg a krumpli majdnem megpuhul.
8. Hozzáadjuk a **maradék nyers kolbászt** karikázva.
9. Amikor a kolbász is megfőtt, visszatesszük a **sült kolbászt** is.
10. Végén megszórjuk aprított petrezselyemzölddel.

---

## Megjegyzések

- A kétféle kolbász (sült + főtt) adja a jellegzetes ízét — ne hagyd ki a sütési lépést
- Babérlevelet a végén kivesszük tálalás előtt
- Önmagában megállja a helyét, nem kell külön köret
