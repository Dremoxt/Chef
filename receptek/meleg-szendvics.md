# 🥪 Meleg szendvics

**Kategória:** Gyors vacsora
**Elkészítési idő:** ~15 perc
**Adag:** 5 fő

**Előkészíthetőség:** 🔴 Frissen, aznap készítendő — frissen, melegen az igazi

**Szezonalitás:** 🌿 Egész évben

**Gyakoriság:** 🔁 Heti 1-2× — gyors

## Gyerekek
- 🟢 Mindenki eszik — gyerekek kedvence!
