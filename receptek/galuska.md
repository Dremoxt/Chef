# 🥟 Galuska (nokedli)

**Kategória:** Köret
**Elkészítési idő:** ~15 perc
**Adag:** 4–5 adag

> Főleg csirkepaprikáshoz, de más pörköltökhöz is illik.

**Előkészíthetőség:** 🔴 Frissen, aznap készítendő — frissen a legjobb, állva összeragad

**Gyakoriság:** 🔁 Igény szerint — köret

## Gyerekek
- 🟢 Mindenki eszik

---

## Hozzávalók

| Összetevő | Mennyiség | Megjegyzés |
|-----------|-----------|------------|
| Tojás | 3 db | |
| Liszt | 200 g | |
| Tejföl | 1,5 ek | |
| Só | 2 csipet | a tésztába |
| Víz | igény szerint | ha a tészta túl sűrű |
| Só | bőven | a főzővízbe |

---

## Elkészítés

1. A tojásokat, lisztet és a többi hozzávalót simára keverjük. A tészta legyen sűrűbb mint a palacsinta, de folyjon le a kanálról.
2. Ha szükséges, kis vízzel lazítjuk.
3. Nagy fazékban sós vizet forralunk.
4. Nokedliszaggatóval (vagy kanállal) kis galuskákat szaggatunk a forrásban lévő vízbe.
5. Amikor feljönnek a víz felszínére, még 1-2 percig főzzük, majd leszűrjük.
6. Szűrés után leöblítjük hideg vízzel, hogy ne ragadjanak össze.

---

## Megjegyzések

- A tészta állaga kulcsfontosságú: sűrűbb mint a palacsinta, de folyjon le a kanálról
- Hideg vizes leöblítés szűrés után megakadályozza az összeragadást
