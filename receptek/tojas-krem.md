# 🍳 Tojáskrém pirítóson

**Kategória:** Gyors étel / vacsora
**Elkészítési idő:** ~15 perc
**Adag:** 2 fő *(5 főre 7-8 tojás, 25 dkg vaj, 2-3 ek tejföl)*

**Előkészíthetőség:** 🟢 Előző nap elkészíthető — hűtőben eláll, lehűtve is finom

**Gyakoriság:** 🔁 ~2 hetente 1×

## Gyerekek
- 🔴 Egyik gyerek sem eszi — tojáskrém estéken a gyerekeknek alternatív vacsorát kell tervezni

---

## Hozzávalók (2 főre)

| Összetevő | Mennyiség | Megjegyzés |
|-----------|-----------|------------|
| Tojás | 3 db | |
| Vaj | 10 dkg | |
| Tejföl | 1 ek | |
