# 🥒 Cukkini krémleves

**Kategória:** Leves
**Elkészítési idő:** ~35 perc
**Adag:** 5 fő

**Előkészíthetőség:** 🟢 Előző nap elkészíthető — felmelegítve is jó

**Szezonalitás:** 🌿 Egész évben

**Gyakoriság:** 🔁 ~2 hetente 1× — leves-rotáció

## Gyerekek
- 🔴 Legnagyobb gyerek — nem eszi
- 🟢 Középső gyerek — eszi
- 🔴 Legkisebb gyerek — nem eszi

---

## Hozzávalók

| Összetevő | Mennyiség | Megjegyzés |
|-----------|-----------|------------|
| Cukkini | 4 db nagyobb | felkockázva |
| Burgonya | 2 db közepes | felkockázva |
| Vöröshagyma | 1 nagyobb fej | felszeletelve |
| Fokhagyma | 4 gerezd | aprítva |
| Tejföl | 100–150 g | |
| Alaplé | igény szerint | ellepje a zöldségeket |
| Olívaolaj | 2–3 ek | |
| Só, bors | ízlés szerint | |

---

## Elkészítés

1. A hagymát olívaolajban megpirítjuk.
2. Hozzáadjuk az aprított fokhagymát, együtt pirítjuk amíg megpuhul.
3. Hozzáadjuk a felkockázott cukkinit és burgonyát.
4. Felöntjük alaplével, puhára főzzük.
5. Hozzáadjuk a tejfölt, sózzuk, borsozzuk, összeforraljuk.
6. Botmixerrel krémesre turmixoljuk.
